Exact commands (live path)

This is the real demo judges should see — terminal, not this page. 

# 1. Setup (once)
uv sync --all-extras
uv run mizani setup

# 2. End-to-end demo → DRAFT brief + release gate
uv run mizani demo --planner deterministic

# 3. Human-only release (agent cannot do this)
uv run mizani approve --brief briefs/drafts/<file>.md --as "Your Full Name" --note "reviewed"

# 4. Prove the evidence chain
uv run mizani ledger verify

# Optional: real Kenya OCDS (registry publication 147)
uv run mizani fetch --year 2026
uv run mizani demo --real --planner deterministic
